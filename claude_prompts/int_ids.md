**Code written (PypeIt repo, new branch `int_ids` off `develop`):**

- `pypeit/spectrographs/int_ids.py` — new `INTIDSSpectrograph` class modeled
  on `mmt_bluechannel.py`. Notable choices:
  - `get_detector_par` reads gain/RN/`TRIMSEC`/`BIASSEC` from the ext-1 header
    and flips the FITS (x,y) section strings into numpy (spec,spat) order via a
    small `_fits_to_pypeit_section` helper; platescale switches on `DETECTOR`
    (EEV10 = 0.40, RED+2 = 0.44); `dataext=1`, `specaxis=0`.
  - `get_rawimage` just calls the base class with `sec_includes_binning=True`
    since the header sections are in read-out (windowed/binned) coordinates.
  - `compound_meta` converts sexagesimal RA (hours) / DEC (deg) to decimal
    degrees, parses space-separated `CCDSUM` (x-bin first, so spatial,spec),
    and maps blank `AGARCLMP` to 'off'.
  - Configuration keys: `dispname` (GRATNAME), `cenwave` (CENWAVE),
    `detector` (DETECTOR), `binning`.
  - Frame typing by `idname` (IMAGETYP); science/standard split by exposure
    time (see Q&A #2).
  - Wavelengths: `holy-grail` with NeI/ArI/ArII/CuI (no template yet);
    long-slit edge params (`sync_predict='nearest'`, `bound_detector=True`).
- `pypeit/spectrographs/__init__.py` — registered `int_ids` (alphabetical).
- `pypeit/telescopes.py` — added `INTTelescopePar` (Roque de los Muchachos

- `pypeit/par/pypeitpar.py` — added 'INT' to `valid_telescopes`.
