# Design GP host subtraction for PypeIt

## Goals

Integrate HostSub_GP (dev_hostsub/refs/HostSub_GP; Liu & Miller 2025) with
PypeIt so that host subtraction is configured entirely from the .pypeit file,
replacing the separate hostsub_setup + hostsub.txt step.

HostSub_GP is a post-processor: it reads spec2d/spec1d of the standard and all
science exposures of a target, downloads archival host images, coadds, fits a
2D GP host model, and writes *_hostsub.fits. The integration must respect that.

Candidate approaches (to be evaluated, not assumed):
- A. In-pipeline step inside run_pypeit
- B. Optional afterburner at the end of run_pypeit when [hostsub] is set
- C. New pypeit_hostsub script reading a new HostSubPar from the .pypeit file

Constraints:
- HostSub_GP and its JAX/tinygp deps must remain OPTIONAL for PypeIt
- With hostsub disabled, PypeIt output must be unchanged
- Out of scope: echelle, IFU, fiber pypelines; non-longslit data

What I learned:
- hostsub_gp is on the same commit as develop (2.0.1-1356). Against
  develop, HostSub's --coadd2d spec1d writer is broken in three places:
  `extract.extract_boxcar` changed signature and no longer takes a SpecObj
  (commit db453e9b4, 2026-02-26); `extract.fit_profile` moved to
  `core.spatialprofile`; and `SpecObj.BOX_RADIUS` no longer exists (renamed
  to `BOX_R_PIX` after 1.17.0, so this is broken on release too). The core
  path (Spec2DObj load, AllSpec2DObj write-back, SpecObjs reading) is fine.
- `PypeItPar.from_dict` whitelists its top-level keys, so a `[hostsub]`
  block in a .pypeit file raises ValueError today. Approach C also needs a
  HostSubPar registered in PypeItPar.
- HostSub hard-codes per-instrument geometry for LRIS, Binospec, ALFOSC and
  FORS2, reads raw headers via `raw_dir`, and matches target/std files by
  filename substring.
  `inputfiles.matching_science_rows` and
  `outputfiles.existing_spec2d_files` (used by setup_datacube) are
  reusable replacements.
- In non-coadd mode, HostSub writes back the last exposure's model to
  every exposure (asked as Q8).
- SpecObj `FWHM` is in pixels (`SPAT_FWHM` is arcsec), so HostSub's seeing
  conversion is correct.
- The cookbook says outputs go in Science/, but the code writes to
  Science_hostsub/.
