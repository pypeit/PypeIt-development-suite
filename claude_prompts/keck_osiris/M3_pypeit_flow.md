identity tilts and Keck-coefficient wavelengths, so that `run_pypeit` on the Hn3/100

## Tasks

1. `rawimage.py`: add a `rectify` step (after dark subtraction and the
   BPM, before cosmic-ray masking) that runs only when
   `spectrograph.has_rectification` is True; it calls
   `spectrograph.rectify(image, ivar, bpm, headarr, par)` and replaces
   `image`, `rn2img`, `proc_var`, `datasec_img` and the BPM with the
   rectified versions.  Default off; existing tests must still pass.
   `KeckOSIRISSpectrograph.rectify` selects and caches the matrix and
   calls `lenslet_rectify`.
2. Fiber hooks in `keck_osiris.py` (design 4.7): `get_fiber_blocks`,
   `get_block_slit_edges` (fixed block boundaries every 64 slices),
   `identify_fibers_in_block`, `get_fiber_metadata`, `load_sky_layout`,
   `get_science_fiber_layout_indices`, `ifu_sky_wcs`, `get_wcs`,
   `get_datacube_bins`, all narrowband-aware through
   `narrowband_split`.
3. Identity tilts: base-class hook `Spectrograph.get_fixed_tilts(slits)`
   (returns a `WaveTilts` with zero tilt coefficients) and the
   corresponding branch in `Calibrations.get_tilts` so no tilt frame is
   needed when the hook exists.
4. Wavelengths from the Keck coefficients: build a `WaveCalib` with one
   `WaveFit` per block (polynomial lambda(pixel) obtained by inverting
   the Keck pixel(lambda) relation, including the grating-temperature
   term from DTMP7 with a warning and no scaling when absent) and the
   per-lenslet shift table consumed by the Fiber pypeline's per-fiber
   shift machinery.  Add the `method = 'fixed'` option to
   `WavelengthSolutionPar` (`add-parameter`) and the branch in
   `Calibrations.get_wv_calib`.  Mark the wavelengths as vacuum in the
   spec1d header.
5. Check `FiberFindObjects`/`FiberExtract` with one-row fibers and no
   flat (uniform profile fallback, boxcar radius of one row); fix any
   multi-pixel-fiber assumption you find and note it in the report.
6. Unit tests: tilt hook, wavelength inversion round trip on the shipped
   coefficients, block/lenslet mapping for broadband and narrowband.
7. Run `run_pypeit` on `keck_osiris_hn3_100.pypeit`; iterate until it
   completes; then run the OH-line tilt test (design Section 8, test 3)
   on the rectified sky frame and add it to the dev-suite vet tests.

## Acceptance

`run_pypeit` on `Hn3_100` completes; the spec1d file holds ~1000 lenslet
spectra with `MASKDEF_ID` = lenslet id and vacuum wavelengths; the
OH-line tilt test passes (fitted tilt slope < 0.05 px over a block,
per-lenslet centroid scatter < 0.1 px after the Keck shifts); a
collapsed image of the quasar from the spec1d matches the DRP cube
position.  All existing PypeIt unit tests still pass.
