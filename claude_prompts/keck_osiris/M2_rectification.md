## Tasks

1. `pypeit/core/lenslet_rectify.py`:
   - `RectMatrix`: load `hilo`, `effective`, `influence` and the header
     parameters; parse `sYYMMDD_cNNN___infl_<filt>_<scale>.fits`;
     `select_matrix(dir, filter, scale, mjd)` returns the latest matrix
     with date <= MJD or raises a `PypeItError` listing what was found.
   - `rectify_drp(image, bpm, matrix, niter=40, relax=1.0, noise=None)`:
     faithful vectorised port of the C solver (blame = B^3/sum,
     final blame = B/sum; iterations 0-14 accumulate and apply with
     the +/-64-slice coupling of +0.4 (iters < 10) and -0.2
     (iters 10-14); iterations >= 15 plain back-projection; 5-tap
     spectral smoothing at iterations 12-17; divide by 1.28; output
     mask good where > 4.5/9 of the kernel weight falls on good pixels;
     DRP noise propagation).  Returns image, ivar, mask of shape
     (2048, nslice).
   - `rectify_lstsq(image, ivar, bpm, matrix)`: batched per-band
     weighted least squares (64 bands x 2048 columns; <= 19 unknowns
     each) with ivar propagation and the same mask rule.
   - `narrowband_split(filter)`: slice -> lenslet (row, col) map for
     broadband (identity, 19 x 64) and narrowband (the `assembcube`
     offsets 0/+16/+32 and the `sp > 831` remainder).
   - `resample_to_drp_grid(rect, matrix, filter, coeffs, dtmp7)`: apply
     the Keck wavelength relation and interpolate each lenslet onto the
     DRP cube grid (for the comparison only).
2. New parameters (`add-parameter` skill) in `CalibrationsPar`:
   `osiris_rectmat_dir`, `osiris_rect_method` ('drp'|'lstsq', default
   'drp'), `osiris_rect_niter` (40), `osiris_rect_relax` (1.0),
   `osiris_rect_use_var` (False).  Regenerate the parameter docs.
3. Script `pypeit_osiris_rectify` (`new-script` skill): inputs raw frame
   (optionally minus a second frame), matrix path or directory, method;
   output a FITS with the rectified image, ivar and mask and the raw
   header.
4. Dev-suite vet test `vet_tests/test_keck_osiris_rectify.py`: rectify
   `s160321_a002010 - s160321_a002011`, resample, compare per spaxel
   with `ref/s160321_a002010_Hn3_100_ref.fits`; also compare the two
   solvers.
5. Unit test with a synthetic 32-row band (known input spectra, known
   PSFs) for both solvers in `pypeit/tests/test_lenslet_rectify.py`.
6. Time both solvers on a full frame and record the numbers.

## Acceptance

Median absolute fractional difference to the DRP reference cube < 2 %
on spaxels with S/N > 10 and quasar-spaxel flux within 5 %; `lstsq`
agrees with `drp` to the same tolerance; synthetic-band unit test
recovers the input to < 1 %; full-frame run time < 60 s (`drp`) and
< 10 s (`lstsq`).  Include difference images and a per-lenslet
comparison plot in the report.

Write `pypeitdev/keck_osiris/Reports/04_m2_rectification.md` describing what was
built, how it was verified (commands and outputs), and anything that
deviates from the design document, and update
`keck_osiris_implementation.md` if the plan changed.
