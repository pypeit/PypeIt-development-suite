## Coding

Here are guidelines for coding:

- Use Python where possible
- Add inline comments to explain the effort
- Reuse existing code when possible
- Place import statements at the top of the file.
- Limit lines of code to 80 characters per line
- Include a description of inputs/outputs in the doc string of all methods
- Add "Generated by JXP and Claude" in the doc string of all methods you create
- Use `from pypeit import log` and `PypeItError`, never `msgs`
- Use `pathlib` for paths
- Do not commit or push; I do all git operations

## Tasks

1. Write `KeckOSIRISSpectrograph` (`pypeline = 'Fiber'`, `supported = False`)
   following design Section 4: class attributes; `init_meta` and
   `compound_meta` (exptime = ITIME x COADDS with ITIME/1000 when
   ITIME > 2000; `instrument` from CURRINST with INSTRUME fallback;
   `posang` from ROTPOSN/INSTANGL; weather defaults with warnings;
   optional ISSKY, DTMP7, PA_SPEC); `configuration_keys`
   (`['dispname', 'decker']`); `raw_header_cards`; `pypeit_file_keys`;
   `check_frame_type` (design 4.3, including science frames also typed
   `trace`, `arc`, `tilt`); `get_detector_par` (read noise from
   SAMPMODE/NUMREADS); `get_rawimage` (DN conversion, era check raising
   `PypeItError` for MJD < 57388, VAR/DQ kept available); `bpm`
   (DQ != 9 OR static hot OR static dead masks); `default_pypeit_par`
   (design 4.8 without the new rectification parameters; no dark
   subtraction for paired frames, Q&A 23).
2. Register the module in `pypeit/spectrographs/__init__.py`
   (alphabetical).
3. Add static files: `pypeit/data/static_calibs/keck_osiris/` (the two
   OsirisDRP masks, gzipped) and `pypeit/data/spectrographs/keck_osiris/`
   (the 11 wavelength-coefficient files, an epoch table derived from
   `calibrations.xml`, the aluminium CTE table from `assembcube_000.pro`,
   the slice-to-lenslet maps).  Add loader helpers on the class.
4. Unit tests in `pypeit/tests/test_keck_osiris.py` using synthetic
   headers for the 2015, 2016-truncated, 2016-full and 2024 card sets
   (values in Report 01 and Report 02): exptime units, frame typing,
   era rejection, static-file loading, `load_spectrograph('keck_osiris')`.
5. Dev suite: add `keck_osiris` with setups `Hn3_100` and `Kbb_050` to
   `test_scripts/setups.py`; write `pypeit_files/keck_osiris_hn3_100.pypeit`
   and `keck_osiris_kbb_050.pypeit` with `comb_id`/`bkg_id` filled by
   hand (A-B pairs: Hn3 010-011; NGC 3245 object/sky pairs by ISSKY and
   time order; A0V nod pairs); add an entry to
   `unit_tests/test_load_images.py`.
6. Run `pypeit_setup -s keck_osiris -r <dir>` on the three directories
   and `pypeit_obslog`; fix what fails.

## Acceptance

`pypeit_setup` on `Hn3_100`, `Kbb_050` and `Kn5_035` gives the expected
types (science/sky/standard/dark, plus trace/arc/tilt on science), one
configuration per directory; the 2015 directory raises the pre-2016
error at `run_pypeit`; `pytest pypeit/tests/test_keck_osiris.py` and
the load-images unit test pass.

Write `pypeitdev/keck_osiris/Reports/03_m1_skeleton.md` describing what was
built, how it was verified (commands and outputs), and anything that
deviates from the design document, and update
`keck_osiris_implementation.md` if the plan changed.
